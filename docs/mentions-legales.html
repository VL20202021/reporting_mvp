Données personnelles

  • Aucun formulaire, aucun cookie, aucun outil de mesure d'audience n'est utilisé sur ce site.
  • Le choix de langue (FR / EN) est enregistré dans votre navigateur (stockage local) uniquement lorsque vous cliquez sur le bouton de langue. Il n'est jamais transmis à la société. Vous pouvez l'effacer à tout moment en supprimant les données du site dans votre navigateur.
  • Les polices de caractères sont hébergées sur le site lui-même : aucune donnée n'est envoyée à Google ou à un autre tiers pour les afficher.
  • L'hébergeur GitHub peut enregistrer l'adresse IP des visiteurs à des fins de sécurité et de fonctionnement du service, selon sa propre déclaration de confidentialité. Ces données peuvent être traitées aux États-Unis.
  • Si vous nous écrivez par e-mail, nous utilisons vos données uniquement pour vous répondre et assurer le suivi commercial de votre demande (intérêt légitime), et nous les conservons au maximum 3 ans après le dernier contact.
  • Vous disposez d'un droit d'accès, de rectification, d'effacement, d'opposition et de limitation : écrivez à contact@votre-domaine.fr. Vous pouvez aussi saisir la CNIL.
