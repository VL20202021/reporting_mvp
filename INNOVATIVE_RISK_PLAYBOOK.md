# Innovative Risk Playbook

Personal rules for taking bold bets without betting everything.

## 1. Make the downside affordable first
- Set a **loss budget** (time / money / reputation) before starting.
- Two-way doors (reversible): move fast. One-way doors (irreversible): slow down.

## 2. Shrink the bet until it's cheap to be wrong
- Name the **riskiest assumption**, the one that kills the idea if false.
- Test only that, as cheaply as possible (mockup, fake door, manual "Wizard of Oz" version, spike, short pilot).
- Write **success / failure criteria and next actions before** running the test.

## 3. Barbell portfolio
- ~70–80% of effort on proven work, ~20–30% on bold bets.

## 4. Separate decision from outcome
- Judge bets by the quality of the reasoning, not only the result.
- Keep a **decision log**: bet, assumptions, expected result, actual result.

## 5. Lower the social risk
- Frame it as an experiment, not a launch.
- Get a sponsor and agree on **kill criteria** up front.
- Share early. Surprises cost credibility; failed experiments don't.

## 6. Keep moving after a result
- After every test: **persevere, pivot, or kill**. No zombie projects.

---

## Pre-bet checklist
- [ ] Loss budget defined
- [ ] Reversible or irreversible?
- [ ] Riskiest assumption named
- [ ] Cheapest test chosen
- [ ] Success / failure criteria written in advance
- [ ] Kill criteria and deadline set
- [ ] Fits the 70/30 barbell
- [ ] Logged in the decision log
- [ ] Stakeholders told it's an experiment
